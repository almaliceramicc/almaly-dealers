# Мгновенные ответы бота: мост на Cloudflare Worker

Telegram доставляет сообщения боту двумя способами: сам толкает их на ваш адрес (вебхук)
или отдаёт по запросу (опрос). Вебхук напрямую с Apps Script не работает — тот отвечает
на POST редиректом, а Telegram по редиректам не ходит («Wrong response from the webhook:
302 Found»). Опрос работает, но реагирует до минуты и тратит суточный лимит триггеров.

Воркер решает это: принимает обновление от Telegram, сразу отвечает «ок» и передаёт
сообщение скрипту в фоне, проходя редирект. Бесплатного тарифа (100 000 запросов в сутки)
хватает с запасом.

## Настройка

1. `dash.cloudflare.com` → **Workers & Pages** → **Create** → **Worker** → имя, например `almali-bot`.
2. **Deploy**, затем **Edit code** — вставить содержимое `worker.js`.
3. В первых строках указать:
   - `APPS_SCRIPT` — адрес веб-приложения из `docs/config.js` → `ORDERS_API`;
   - `SECRET` — любую длинную строку; она же передаётся Telegram в `secret_token`.
4. **Deploy**. Скопировать адрес воркера вида `https://almali-bot.<имя>.workers.dev`.
5. Переключить бота на вебхук:

   ```
   https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=<АДРЕС_ВОРКЕРА>&secret_token=<SECRET>
   ```

6. В Apps Script удалить триггер `pollBot` (Мои триггеры → корзина): опрос больше не нужен,
   а вместе с вебхуком он будет мешать — Telegram отдаёт сообщение только одному из них.

Проверка: `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo` — в ответе должен быть адрес
воркера и пустое `last_error_message`.

Вернуться к опросу можно в любой момент: выполнить `setupBot` в Apps Script —
она снимает вебхук и заново создаёт триггер.
